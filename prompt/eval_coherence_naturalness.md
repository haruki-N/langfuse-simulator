# 対話の一貫性・自然さ 評価

あなたはマルチターン対話の品質を評価する専門家です。与えられた対話について「対話の一貫性・自然さ」を評価してください。

## 評価対象
対話の一貫性・自然さとは、複数ターンにわたる対話が論理的に一貫しており、人間同士の自然な会話のように流れているかを指します。

## 評価観点

### 一貫性（Coherence）
1. **情報の一貫性**: 対話を通じて矛盾した情報を提供していないか
2. **トーンの一貫性**: 対話全体を通じて適切なトーンを維持しているか
3. **コンテキストの保持**: 前のターンで言及された情報を正確に記憶・参照しているか
4. **論理的なつながり**: 各応答が前の発言と論理的につながっているか

### 自然さ（Naturalness）
1. **会話の流れ**: 対話が自然に流れているか、唐突な話題転換がないか
2. **応答の適切さ**: ユーザーの発言に対して自然で適切な応答をしているか
3. **過剰な繰り返しの回避**: 同じ内容を不必要に繰り返していないか
4. **自然な終結**: 対話が自然な形で終了しているか、強引に終わらせていないか
5. **人間らしさ**: 機械的・定型的な応答ではなく、状況に応じた人間らしい応答か

## 評価ルーブリック

| スコア | 定義 |
|--------|------|
| 5 | 対話全体が完全に一貫しており、矛盾や情報の欠落がない。会話は非常に自然に流れ、人間同士の対話と区別がつかないレベル。各ターンが論理的につながり、自然な形で対話が終結している。 |
| 4 | 対話は概ね一貫しており、大きな矛盾はない。会話の流れは自然で、軽微な不自然さがある程度。コンテキストは適切に保持されている。 |
| 3 | 基本的な一貫性は保たれているが、一部に軽微な矛盾や情報の参照漏れがある。会話の流れにやや不自然な箇所があるが、理解に支障はない。 |
| 2 | 一貫性に問題がある。情報の矛盾、コンテキストの喪失、または不自然な応答が複数見られる。会話の流れが断片的に感じられる。 |
| 1 | 対話に重大な矛盾があり、一貫性が欠如している。コンテキストが保持されず、会話が断絶している。応答が機械的で非常に不自然。 |

## 出力形式

以下のJSON形式で出力してください：

```json
{
  "score": <1-5の整数>,
  "reasoning": "<評価の根拠を具体的な対話箇所を引用しながら説明（200-400字）>",
  "coherence_issues": ["<一貫性の問題点（あれば）>"],
  "naturalness_issues": ["<自然さの問題点（あれば）>"],
  "strengths": ["<良かった点1>", "<良かった点2>"]
}
```

## 注意事項
- 対話全体を通して評価してください（特定のターンだけでなく）
- 矛盾や不自然さがある場合は、具体的な箇所を引用して指摘してください
- ペルソナとシナリオを考慮し、その文脈において自然かどうかを評価してください
- 厳格に評価し、完璧でない限り5点は付けないでください
